# Kiru typography assets

Unmodified upstream variable TTFs obtained from Google Fonts (ofl/notosanssc, ofl/manrope, ofl/spacegrotesk, ofl/geistmono). Individual SIL OFL licenses are included. The runtime creates script-specific aliases in memory; no modified font is distributed. MiSans is not bundled; users may acquire it from Xiaomi and import it for the Chinese role subject to its license. The Chinese fallback is Noto Sans SC.
