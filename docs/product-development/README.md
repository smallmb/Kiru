## 已确定
- 使用 ZPlay 现有 Flutter 工程，不重新造轮子；保留顶部内容类型切换及播放源展示交互。
- 核心产品是电影、剧集、动漫及多源高清播放；已有媒体类别可扩展。
- 外部适配隔离、内部按业务模块聚合；小步迁移，不为目录结构重写稳定功能。
## 暂定决策
- Windows 优先，其次 Android；其他平台后续以实际可构建性排期。
- Local-first，不强制账号，不新增服务端；中文优先，保留现有语言。
- 产品名称、视觉主色、音乐/阅读/成人内容入口是否暴露待确定。成人内容入口默认不作为核心功能，建议隐藏并审计。
- 所有新接入源须合法授权或由用户提供合法资源；不得以绕过 DRM 为目的。
- GPL-3.0 及第三方许可按本地 LICENSE 和实际依赖复核；分发时履行义务。
