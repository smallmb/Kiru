# 产品需求文档（PRD）
## 1. 产品定位
基于 ZPlay 构建现代化全平台影音客户端：影视发现、多源选择、高清播放、个人媒体管理。与单纯本地播放器不同，强调从内容发现到观看的闭环；与单一在线源不同，强调可替换的来源与个人媒体库。
核心用户：日常看电影/剧集/动漫的用户、对画质与字幕有要求的影音用户、管理个人 NAS/媒体服务器的用户。
产品原则：免强制注册、使用本地优先、来源透明、播放稳定、视觉统一、平台能力可检测、合法资源。

## 3. 信息架构
现有 ShellSlot 为 home/browse/search/library/settings，桌面、平板、电视采用顶部导航，手机底部导航。保留这层结构；浏览页内部保持顶部电影/剧集/动漫等分类切换，不将其误拆成重复的全局导航。
首页：继续观看、精选推荐、热门内容、类别入口；影视浏览：类型/地区/年份/排序筛选；动漫：番剧/新番时间表（元数据可用时）、追番；搜索：全局查询、历史、过滤、空状态；详情：海报、简介、评分、演员、季/集、播放与收藏；播放源：保持现有 WatchScreen 的展示逻辑；媒体库：收藏、历史、下载、本地/服务器（分阶段）；设置：外观、语言、播放、来源、网络、存储、隐私、关于。
## 4. 核心用户流程
- 首次启动 → 选择语言/基础设置 → 首页；无任何源时可浏览公开元数据，并有清晰的来源配置说明。
- 浏览/搜索 → 详情 → 选择季集 → 加载播放源（逐步展示） → 选择合法可用源 → 播放 → 记录进度 → 首页继续观看。
- 播放失败 → 显示原因/重试 → 用户切换备用源 → 在同一影片/集数恢复进度。
- 本地文件 → 打开/播放 → 可选刮削 → 收藏/历史；无需网络亦可播放本地内容。
- 添加私人服务器 → 连接测试 → 浏览授权媒体 → 播放；令牌存储在平台安全存储。
## 5. UX 验收约束
- 视觉修改前确定统一 design tokens；保留 ZPlay 顶部分类和来源卡片的结构，非必要不替换布局。
- 桌面鼠标/键盘、移动触控、TV 遥控焦点分别适配；页面切换保留滚动、筛选与搜索状态。
- 加载、空数据、网络故障、无源、过期源、不可解码、权限不足必须区别处理。
- 源标注显示分辨率、编码、HDR、大小等已知信息；未知明确标为未知，不能伪造 4K 或速度。
- 4K 是片源与设备/内核联合能力；超分输出不能标作原生 4K。
## 6. 非目标与待确认
首版不新增付费订阅、强制账户、云端中转、全量自研播放器；不承诺所有设备 Dolby Vision/HDR/AV1；不承诺第三方片源永久免费或可用。
待确认：品牌命名、图标、主题基准、具体支持平台、音乐/阅读是否作为独立入口。以上未定项不阻塞 M0/M1 基础开发。
