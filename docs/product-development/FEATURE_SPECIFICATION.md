# 功能详细设计
## 1. 发现与搜索（F01）
复用 HomePage、Browse、Search、Details；保留顶部分类组件、IndexedStack 与页面状态。先统一 UI token、中文资源和卡片规格，再增加筛选。
首页展示精选、继续观看、热门电影/剧集/动漫；数据源失败时独立降级，不阻断其他区域。分类支持类型、地区、年份、排序（以实际 API 能力为限）。搜索防抖、取消过期查询、区分同名作品并显示年份/类别。详情展示可用元数据、季度/集数、收藏；海报/简介缺失有占位，不伪造评分。
验收：切换分类保留状态；搜索进入详情并正确选集；不同作品 ID 不混淆；中文界面无溢出。
## 2. 播放源（F02）
复用 WatchScreen、StreamService、AddonManager、BestSourceFinder、StreamHealthChecker。第一步记录现有行为和 UI 截图；在不改变原交互前提下提取查询状态、列表组件、筛选逻辑与播放交接。
状态：idle、loading、partial、complete、empty、error、cancelled。显示每个来源名称、已知分辨率/格式/编码/HDR/大小、可用状态；声明信息与实际播放检测区分；未知项不编造。支持全部/4K/1080p/720p、来源、可用状态筛选；按偏好/兼容性排序。查询过程中稳定展示已到达结果；切换选集清除旧会话。
来源设置：启停、排序、配置、连接测试、删除、权限提示；第三方协议能力按平台检测；来源失效不阻断其他来源。首版以用户授权 URL、合法 Stremio 扩展和测试素材验收；既有内置来源先审核版权、权限与合规，不默认认定合法。
验收：两个模拟来源一快一慢、一个失败，快速结果可立即选择；取消后无陈旧数据；同一媒体/集数切源恢复进度；空结果有配置指引。
## 3. 播放器（F03）
保留 media_kit 定制分支和现有 VideoEngine/ExoPlayer。优先盘点真实平台能力，不盲目添加另一套内核。
基础：播放/暂停、进度、音量、倍速、全屏、键盘/触控/遥控器、选集、自动连播。
画质：原生 4K、H.264/HEVC/AV1 等按平台兼容检测；Anime4K 与 FSR 独立开关、预设、禁用回退；HDR 和 Dolby Vision 按实际能力展示，不宣称全平台支持。
字幕/音频：内嵌/外部字幕、语言切换、样式、时间偏移、多音轨、音画同步；不支持的功能显示限制。
诊断：实际分辨率、帧率、编码、解码器、HDR 状态、丢帧与缓冲（引擎可报告时）；未知标为未知。错误类型含网络、源过期、格式不支持、权限、引擎初始化。重试有上限，提示用户手动切源。
验收：合法 1080p/4K 素材测试；播放、拖动、字幕、音轨、退出及续播；画质开关可回退；播放失败不会卡死主界面。
## 4. 个人影音（F04）
复用 continue_watching、my_list、collections、profiles 与现有下载功能。统一媒体 ID 与集数；进度写入采用节流，退出刷新；仅在正片观看后更新进度，预告不污染历史。收藏、追番、历史、继续观看支持删除和清空确认；继续观看应重新解析有效源。
验收：重启后记录保留；同一集不同源共享进度；取消/失败不覆盖有效进度；升级后原有记录不丢失。
## 5. 私人媒体库（F05）
分步：本地文件 → 授权目录扫描 → 元数据匹配及手动纠正 → WebDAV/Jellyfin → SMB 等按实际依赖评估。扫描可取消，增量索引，跳过无权限目录，禁止递归符号链接循环；本地文件移动或删除时标记不可用。
服务器配置：名称、协议、端点、账号引用、连接测试；令牌安全存储；不把个人文件路径/账号/令牌发送给非必要服务；删除配置不删除远端媒体。
验收：本地文件离线播放、手动匹配、服务器鉴权错误、断线恢复、凭据不出现在日志。
## 6. 设置与其他（F06）
外观：统一现有主题 token、深浅模式、系统跟随；语言：简体中文+已有语言。播放：引擎、硬解、字幕、画质、网络缓冲。来源：权限、启停、配置。数据：备份恢复（默认不导出敏感凭据）、缓存清理、隐私。关于：版本、版权、第三方许可、独立更新渠道。
扩展功能：直播、投屏、授权下载、音乐/漫画/有声书、AI 字幕等不抢占核心闭环开发资源。按功能开关管理入口，隐藏不等于删除。
