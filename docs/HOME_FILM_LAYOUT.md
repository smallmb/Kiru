# Home and film hub

The shell Home uses a curated feed assembled from the existing catalogue stream,
real recommendation lists, variety catalogue extras and the selected anime
metadata provider. The movie destination mounts the original Home feed without
startup splash or ownership of the global header actions. Browse all opens
the existing Discover catalogue grid and its provider-supported filters.
The two page instances reuse the original artwork/playback and shared cache.
Only the active hero auto-rotates. No Arabic anime is requested.

Home modules: featured film/TV, continue watching, popular movies, popular
series, Cinemeta top 10, releases in the last 90 days with known dates,
variety, ratings >= 8, anime picks and genuine personalized recommendation
sections. Empty modules are omitted; title deduplication uses provider identity,
except a ranked list preserves source order. Prefer new titles across shelves
and retain a valid shelf if all candidates overlap. This is not a global
exhaustive ranking or an invented recommendation engine.
